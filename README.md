# ユニバ攻略ナビ

## 2026-10-18の更新

- 写真と乗り物名を押して選ぶ画面へ整理。
- 選んだ乗り物の1日分の待ち時間を、折れ線グラフで表示。
- グラフのタップ、スライダー、1分単位の時刻入力で比較し、並び始め・待ち時間・体験終了の目安を確認して予定に追加。
- 空きやすい時間の候補、希望する2つの組み合わせ、朝の移動を含む順番の比較に対応。
- 時間表には確定した予定を表示。空き行の長い待ち時間文は廃止。

このリポジトリは公開用の生成物です。`index.html` にUIと計算コード、データ・画像を同梱しています。オフライン更新用ファイルは `sw.js` です。開いたままの画面で「新しい版があります」と表示された場合は「読み込む」を押してください。

編集用ワークスペースでは、ルートの `CLAUDE.md` と `_work/攻略アプリ/作業状況.md` に元ファイルの場所、生成方法、確認内容を記録しています。
